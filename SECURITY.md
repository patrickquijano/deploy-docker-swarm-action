# Security Policy

## Supported Versions

Only the latest release, tracked by the major tag `v0`, gets fixes.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |
| < 0.1   | ❌        |

## Reporting a Vulnerability

Do not open a public issue.

Report the vulnerability privately through the [advisory form](https://github.com/patrickquijano/deploy-docker-swarm-action/security/advisories/new). Include:

- the affected version
- a description of the vulnerability
- steps to reproduce it
- its impact

Never include real SSH keys, registry passwords or hostnames in a report.

You can expect an acknowledgement within 7 days.

If the report is accepted, a fix release follows and the advisory is published with credit to the reporter, unless the reporter asks otherwise. If the report is declined, the reasons are given in the advisory thread.
